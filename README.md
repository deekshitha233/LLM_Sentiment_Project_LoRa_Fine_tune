# LLM_Sentiment_Project_LoRa_Fine_tune
Developed an LLM-based Sentiment Analysis project by fine-tuning the Qwen2.5-0.5B-Instruct model using LoRA (Low-Rank Adaptation). The project leverages PEFT to adapt the pre-trained language model for sentiment classification, enabling it to analyze text and predict sentiment categories. Implemented using Python and Hugging Face Transformers.
