# 🤖 LLM-Based Sentiment Analysis using Qwen2.5-0.5B & LoRA

### 📌 Project Overview
- Developed an AI-powered Sentiment Analysis system using **Qwen2.5-0.5B-Instruct**.
- Fine-tuned the pre-trained Large Language Model (LLM) using **LoRA (Low-Rank Adaptation)**.
- Applied Parameter-Efficient Fine-Tuning (PEFT) to adapt the model for sentiment classification.

### 🚀 Key Features
- 🧠 Fine-tuning Qwen2.5-0.5B-Instruct for sentiment analysis.
- ⚡ LoRA-based parameter-efficient model training.
- 📝 Text-based sentiment classification.
- 📊 Dataset preprocessing and preparation.
- 🔍 Model evaluation and performance testing.
- 💻 Interactive sentiment analysis application.

### 🛠️ Technologies Used
- Python
- Qwen2.5-0.5B-Instruct
- LoRA (Low-Rank Adaptation)
- Hugging Face Transformers
- PEFT
- PyTorch
- Natural Language Processing (NLP)

### 🎯 Project Objective
To leverage the capabilities of Large Language Models and parameter-efficient fine-tuning techniques to build an effective AI-based sentiment analysis system that identifies sentiment from textual data.
